# BA Assistant 🤖

*Your AI co-pilot for bulletproof user stories*

## ⚡ The Problem We Solve

**"I want a login feature"** → *2 weeks later* → **"Wait, what about password reset? Error states? Session timeouts?"**

Traditional requirement gathering is broken. Vague requests become incomplete specs, leading to:
- 🔁 Endless clarification cycles
- ❌ Missed edge cases  
- 😤 Frustrated teams
- 🕒 Wasted development time

## 🎯 The Solution

BA Assistant acts as your senior business analyst that **never stops asking questions**. It transforms ambiguous requirements into production-ready user stories through intelligent interrogation and continuous refinement.

## ✨ How It Works

1. **Feed It Anything**  
   - Text descriptions, screenshots, or voice notes
   - "Make the login better" or "Add social auth"

2. **Watch The Magic**  
   - Generates structured user stories
   - **Automatically flags**: unclear requirements, missing acceptance criteria, potential edge cases
   - **Asks smart questions**: "Should users be able to reset passwords via email or SMS?"

3. **Refine & Approve**  
   - Answer questions → Stories update in real-time
   - PM signs off on bulletproof specs
   - Developers get complete requirements from day one

## 🛠 Tech Stack

- **Frontend**: TanStack Start
- **Database**: PostgreSQL
- **AI Workflow**: n8n (triggered via API)

## 🚀 Quick Start

```bash
git clone https://github.com/your-repo/ba-assistant

```
